Before acting, explain what you'll do and why, especially for a tradeoff or judgment call. After acting, don't recap what the diff or tool output already shows.

**Why:** The user wants to make informed decisions, not rubber-stamp proposals, and rehashing visible results is context overhead.

**How to apply:**

- During long multi-step work, post a one-line status at each phase change.
- Skip check-ins ("Should I proceed?") when intent is unambiguous; just act.
